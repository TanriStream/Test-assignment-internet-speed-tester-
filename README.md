# Название скрипта (если есть, вставить сюда)

Простой консольный скрипт на Python для измерения скорости передачи данных с URL.

## Принцип работы:
Скрипт последовательно выполняет 10 HTTP GET-запросов, измеряет время каждого запроса и объем
полученных данных.

После завершения всех запросов рассчитывается среднее время выполнения, общий объем скачанных
данных и скорость загрузки.

## Возможности:
- Выполняет 10 последовательных HTTP GET запросов;
- Дожидается полной загрузки каждого ответа;
- Измеряет время выполнения каждого запроса;
- Рассчитывает среднее время выполнения запросов;
- Подсчитывает общий объем скачанных данных;
- Рассчитывает среднюю скорость скачивания;

## Требования / Зависимости:
- Python 3.10+;
- Библиотека requests;

## Установка:
Склонируйте репозиторий и установите зависимости:
- git clone https://github.com/TanriStream/Test-assignment-internet-speed-tester-.git;
- cd <название-директории>;

## Установка зависимостей:
python -m pip install -r requirements.txt

# Запуск:
python main.py
После запуска укажите URL, с которого необходимо загрузить данные.

## Единицы измерения запросов (тип, как пишется):
- Время (секунды, sec);
- Объем данных (мегабайты, MB);
- Скорость скачивания (мегабиты в секунду, Mbps);
